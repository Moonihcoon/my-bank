## 문서에 반영하면 좋은 보완
1. 수정주가 처리 주의 (위 표).
2. 호출 한도는 "공식 문서 확인일" 병기.
3. 점수 입력 중 업황·재무 자료가 비면 신뢰도를 낮춰 표시한다는 규칙 (구현됨).
4. GitHub Pages 공개 범위 경고 (비공개 저장소여도 사이트는 공개).
